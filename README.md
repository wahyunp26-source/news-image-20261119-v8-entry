The World in One Day — a one-page newspaper front page for Thursday 19 November 2026: 46 stories, 6 regions, a day-by-hours strip, a world map, and a verdict box. Built with pure Python stdlib: the entry decodes its own embedded raster illustrations and pre-rendered typography (Liberation Sans) with a hand-written PNG decoder and composites the page, no third-party packages at runtime.

## Run it

```sh
python3 -P -s main.py
```

Writes `entry.png` (1024×1024).
